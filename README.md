# pairwise-anim-curve-compress

角色跑步动画压缩后，脚底打滑和手臂抖动：曲线按固定误差阈值剔除关键帧，峰值处的误差累积到下一段；四元数逐分量插值没有归一化，旋转出现缩放；三次样条在循环边界没有对齐，首尾速度不连续；压缩只按单轨道评估，左右腿的相位差被破坏；根运动位移被量化到整厘米，长距离漂移；事件帧在压缩后被移动到最近关键帧，脚步声错位；不同帧率的动画共用一套采样表，30 帧和 60 帧混用；曲线压缩后没有重算包围盒，角色被剔除；镜像动画的曲线没有同步压缩，左右不对称；批量压缩时没有保留原始曲线，出问题无法回退。animation/curve_compress.py 是核心，tests/test_curve_compress.py 15个红。要修的是：峰值误差约束；四元数归一化；循环边界对齐；多轨道联合评估；根运动高精度；事件帧锁定；按帧率采样；包围盒重算；镜像同步；原始备份。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
